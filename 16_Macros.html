16.1 / 16.2 — Overview

Macro Overview

A macro is typically an easily initiated, concise program used to perform an often-repeated function. Any program can be assigned as a Macro. To use a macro you must write it, set it up on the Macro Table, and execute it.

Execution Sources — Where Can Macros Run From?
⌨️
Teach Pendant Keys
Manual Mode
User Keys 1–7 (UK) or Shift + User Keys 1–7 (SU). Motion programs must use SU assignment. UK programs cannot contain motion and must have group mask [*,*,*,*,*].
🖥️
Manual Functions Screen
Manual Mode — MF
Accessed via MENU → MANUAL FCTNS. Press SHIFT + F3 (EXEC) to run. Assignment code is MF.
⚡
Input Signal
Automatic Mode
Triggered when a Digital Input (DI), Robot Input (RI), or User Operator Panel Input (UI) signal is received. Up to 10 by default; controlled via $MACROMAXDRI.
🔘
SOP Buttons
Automatic — SOP 4/5
Standard Operator Panel buttons SOP 4 and SOP 5. Assignment only available on RJ3iB and older controllers.
📄
Macro Command Instruction
In-Program Call
Called within another TP program using the MACRO instruction. Behaves identically to a CALL instruction but is referenced by Instruction Name from the Macro Table.
📌
System-level macros are application-specific, predefined instructions identified with the letter "s" at the far right of the Macro SETUP screen. You cannot change their instruction name or program.
Three Steps to Use a Macro
1
Write the Program
Create a Teach Pendant program with the subtype set to Macro. Any program content is valid — motion, I/O, logic, etc.
2
Assign on the Table
Go to MENU → SETUP → MACRO. Place the program in the Macro Command Table and configure the Instruction Name and the assignment type (UK, SU, MF, DI, etc.).
3
Execute
Trigger the macro using the assigned method — press the user key, activate an input signal, select from Manual Functions, or call it from within a program.
16.3 — Creating a Macro

Creating a Macro Program

Creating a Macro is very similar to creating a regular Teach Pendant program. Any program can be used as a Macro — the key difference is setting the subtype to Macro in the program detail screen.

📌
If you create a program from the Select menu with F1 [TYPE] set to Macro, the subtype is assigned automatically. Similarly, any program placed on the Macro Table is automatically given the subtype Macro.
Procedure 16-1: Creating a Macro Program
1
Press the SELECT key

Navigate to the Program Select screen.

2
Press F2, CREATE

If F2 is not displayed, press NEXT first.

3
Enter a descriptive program name

Naming conventions are the same as for regular TP programs. Choose something that describes the macro's function.

4
Press F2, DETAIL

Opens the program detail / header screen.

5
Cursor to Sub type → F4 [CHOICE]

A list of subtypes will appear.

6
Select MACRO from the list

Options shown: None, Collection, Macro, Cond.

7
Press F2, END

Returns to the program editor. Add instructions to the macro program as needed.

16.4 — Macro Assignments

Macro Assignments

Before a Macro can be "fully functioning" it must be assigned on the Macro Table. One program can be assigned to multiple execution methods simultaneously — for example, a HOME program assigned to both a SU key (manual) and a DI signal (automatic).

Manual Mode Assignments
  • UK[1]–UK[7] — User Key (alone) Up to 7 macros mapped to teach pendant user keys. Cannot contain motion instructions. Group mask must be [*,*,*,*,*].
  • SU[1]–SU[7] — Shift + User Key Up to 7 macros triggered by SHIFT + user key. Can contain motion instructions. Suitable for programs that move the robot.
  • MF — Manual Functions Screen Listed on the MANUAL FCTNS macro screen. Press SHIFT + F3 (EXEC) to run. Useful for operator-initiated routines without a dedicated key.
Automatic Mode Assignments
  • DI[x] — Digital Input Executes when the specified DI signal is received. Indexes 0–999 available (0 = no assignment). Input must be properly configured.
  • RI[x] — Robot Input Executes on robot input signal. Maximum 24 in some configurations. Indexes 0 through the configured number of RI signals.
  • UI[x] — User Operator Panel Input Available on some systems. Indexes 0 through the number of configured UOP input signals.
  • SP — SOP Buttons (SOP 4 / SOP 5) Standard Operator Panel buttons. Available on RJ3iB and older controllers only.
⚠️
CAUTION: Make certain that your application has not already assigned functions to the teach pendant user keys; otherwise, execution problems can occur. If making a UK assignment ensure the Group Mask is [*,*,*,*,*,*,*,*].
Procedure 16-2: Making a Macro Assignment
1
Press MENU → SETUP → MACRO → ENTER

Navigate through the flyout menu to reach the Macro Command Table.

2
Review the Macro Command Table

Default items may be listed. Lines with a blank Program column are unassigned.

3
Cursor to open line in Program column

Find an unassigned row (--[0] in the Assign column).

4
Press F4 [CHOICE] → select program

If your program is not listed, press F2 MACRO to filter for Macro-subtype programs. Highlight the target and press ENTER.

5
Program and Instruction Name fill automatically

The Instruction Name column is populated from the program name. If the name already exists, it is left blank with a warning.

6
Edit the Instruction Name (descriptive)

Make the name clearly describe what the macro does. No naming convention rules apply here. This name appears in the MANUAL FCTNS table and in the MACRO Call instruction.

7
Cursor to Assign column → F4 [CHOICE]

Two-part assignment. First field: choose type (UK, SU, MF, SP, DI, RI). Second field: enter the number.

Types: UK / SU / MF / SP / DI / RI
8
Enter the assignment number in the second field

E.g., for UK[1] choose type UK then enter 1.

16.5 — Macro Command Instruction

Macro Command Instruction

Once a Macro assignment is made on the Macro Table, it can also be called directly from within a TP program using the MACRO instruction. It executes identically to a CALL instruction — the only difference is how the line appears (by Instruction Name, not program name).

Procedure 16-3: Programming a Macro Command Instruction
1
Place cursor on target line → F1 [INST]

Press NEXT if INST isn't shown on F1.

2
Navigate to page 2 on [INST] menu

The MACRO option is on the second page of instructions.

3
Select MACRO (option 6)

The instruction list: 1-Skip, 2-Payload, 3-Offset/Frames, 4-Multiple control, 5-Program control, 6-MACRO, 7-FOR/ENDFOR…

4
Choose the program by Instruction Name

Programs are listed by their Instruction Name as defined on the Macro Table — not by program filename.

5
Instruction is added to the program

The line shows the Instruction Name and executes identically to a CALL.

Example: A_PICK_PART with Macro Call
A_PICK_PART
10/13
2:UTOOL_NUM=1
3:
4:J PR[1] 100% FINE
5:J P[1] 100% CNT50
6:L @P[2:Pick Pos] 250mm/sec FINE
7:RO[1]=OFF
8:J P[3] 100% CNT50
9:L @P[4:Place Pos] 250mm/sec FINE
10:Gripper will open// MACRO call
11:J P[3] 100% CNT50
[End]
📌
Line 10 "Gripper will open" is the Instruction Name from the Macro Table — not the program name. It runs the GRIPPER program exactly like a CALL instruction would.

Lab Exercise

LAB 29
Macro Assignments
Create and assign multiple Macro programs, mapping them to various execution methods on the FANUC controller.
  1. Create three Macro Programs (See Section 16.3, pg. 275)
    • HOME
    • REPAIR
    • SAFE
  2. In each program, record the applicable Position Register created during Lab 18
  3. Assign HOME as:
    • A MANUAL FUNCTION (See 16.4.2, pg. 278)
    • A Digital Input (See 16.4.3, pg. 278)
  4. Assign REPAIR as:
    • A Shift User Key (See 16.4.1, pg. 277)
    • A Digital Input
  5. Assign SAFE as:
    • A Shift User Key
    • A Digital Input
  6. Assign A_GRIP_OPEN as UK[1], with instruction name 'Gripper will Open' (See 16.4.4, pg. 279)
  7. Assign A_GRIP_CLOSE as UK[2], with instruction name 'Gripper will Close'
  8. Test all assignments — verify each macro executes correctly from its assigned trigger
📌
Remember: programs assigned to UK[x] (user key alone) cannot contain motion instructions and must have a group mask of [*,*,*,*,*]. Programs that move the robot must use SU[x] (SHIFT + key) assignments.
