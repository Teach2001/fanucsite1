14.2 — I/O Overview

Inputs & Outputs Overview

Inputs and outputs (I/O) are electrical signals that enable the controller to communicate with the robot, end-of-arm tooling, and external devices such as PLCs, HMIs, sensors, and actuators. Think of it like how humans speak (output) and listen (input) — but for machines the signals are electrical.

📡
Signals
The controller core software views all I/O as signals, identified by kind and number — for example DI[1] or GO[2].
📤
Outputs
Can be turned ON or OFF, or set to a value if supported. Outputs are sent from the controller to external devices.
📥
Inputs
Can be read and their values stored so the program can make decisions based on the incoming signal state.
🏭
Applications
Modern manufacturing uses many I/O communication methods. FANUC offers solutions for every preferred interface or application type.
14.3 — Types of I/O

Types of I/O

The available kinds and quantities of I/O depend on the hardware installed. Six types are available in the FANUC system.

DI/DO
Digital I/O
ON / OFF
A single control signal with only two possible states: ON or OFF. Provides access to one input or output signal line. The most common I/O type.
GI/GO
Group I/O
Binary Integer
A sequence of up to 16 digital I/O signals interpreted as a binary integer. Each bit is a single digital line; unused bits are assigned 0.
AI/AO
Analog I/O
-10V to +10V
A voltage signal within the range of the I/O board. Typical range is -10V to 0V or 0V to +10V depending on the hardware device used.
UI/UO
User Operator Panel
18 In / 20–24 Out
Provides 18 inputs and 20–24 outputs connectable to a remote device or panel. Most signals active when robot is in remote condition; safety signals always active.
SI/SO
Standard Operator Panel
Fixed / Read-Only
Internal controller software panel signals. Assignments cannot be changed, but are useful to display during troubleshooting operations.
RI/RO
Robot I/O
EE Connector
Signals between the controller and robot sent to the End Effector (EE) connector. HandlingTool: 8 RI / 8 RO. LR HandlingTool: up to 6 RI / 6 RO.
14.4 — I/O Hardware

I/O Hardware

The hardware type dictates the kinds of I/O available and the number of ports. Each hardware family has different communication, physical, and capability characteristics.

  • Model A I/O Discrete I/O modules communicating with the CPU through an interface module. Requires a backplane in the controller. Supports digital (8/16/32 inputs) and analog (2/4 channels) I/O. Some FANUC software automatically configures Model A at cold start ("Plug and Play").
  • Model B I/O Discrete I/O modules that can have both inputs and outputs on the same unit. Digital only — 24V DC or 120V AC. Uses serial communications with CPU via interface module. No backplane required.
  • Fieldbus / Network I/O DeviceNet, ControlNet (legacy), Profibus, Profinet, EtherNet/IP, EtherCat. These require additional software options and possibly extra hardware to configure.

14.5 — Configuring I/O

Setting Up I/O

Configuring I/O establishes the correspondence between the signal number and the physical port. Each signal must be assigned a Rack, a Slot, and a Starting Point (digital) or Channel (analog).

📌
Power cycle required: After configuring or changing I/O configuration you must turn the controller OFF and back ON for changes to take effect.
1
Rack
Identifies the type of I/O communication. Think of it as the communication medium (like talking vs. email for humans). The physical location where the module or board is mounted.
2
Slot
Identifies the individual module within a rack. Valid values are 1–10, assigned sequentially. The first process I/O board is always slot 1. No duplicate slot numbers within the same rack.
3
Start Point / Channel
The physical position on the module identifying the first port in the range. Called "Start Point" for digital I/O and "Channel" for analog I/O.
Procedure 14-1: Configure Digital I/O
1
Press MENU → Highlight I/O → Digital → ENTER

Navigate via the flyout menu to the I/O Digital screen.

2
Press F2 CONFIG

Switches from the monitor view to the configuration table showing RANGE / RACK / SLOT / START / STAT columns.

3
Toggle Inputs/Outputs with F3 IN/OUT

Switch between the DI and DO configuration screens as needed.

4
Set RACK, SLOT, START values

Cursor to each field, type the value, press ENTER. To delete an assignment set all three to 0 or press F4 DELETE.

5
Verify — valid shows PEND, then cycle power

A valid assignment shows PEND (pending). Cycle controller power to make the change active.

Procedure 14-2: Comment / Polarity / Complementary
1
Navigate to I/O → Digital, cursor to signal
2
Press NEXT → F4 DETAIL

Opens the Port Detail screen with Comment, Polarity, and Complementary fields.

3
Comment: cursor to comment line → ENTER → type name
4

5
Complementary: F4 TRUE / F5 FALSE
Odd output complimented with corresponding even output only. Cycle power required.
14.6 — Group I/O

Group I/O

Group I/O allows "grouping" of Digital Inputs or Outputs so the robot understands them as a single integer (number) based on binary bit values: 1, 2, 4, 8, 16, 32, 64, 128... This enables program selection from a PLC, or turning on/off any combination of outputs with one instruction.

Interactive Binary Group Visualizer
CLICK BITS TO TOGGLE — OBSERVE GROUP VALUE
GO[1] = 0
All bits OFF → value = 0
Procedure 14-3: Configure Group I/O
1
MENU → I/O → Digital → ENTER

Start on the Digital I/O screen to identify the signals you want to group.

2
Press F3 IN/OUT then F2 CONFIG

Display the correct type (DO or DI), then switch to config view to find Rack, Slot, and Start for the signals.

3
Determine group parameters
Find Rack, Slot, Start Point for the first signal
Determine Number of Points (2–16, sequential, same rack/slot)
4
Press F1 [TYPE] → Group → ENTER

Navigate to the Group Output (or Input) screen.

5
Press F2 CONFIG, enter Rack/Slot/Start/Num Pts

Fill in the values determined from the Digital I/O screen.

6
Press NEXT → F2 VERIFY

"Port assignment is valid" confirms correct configuration. Cycle power to enable.

📌
Group signals must be 2–16 points, sequential, and on the same rack and slot. Cannot span across racks or slots.

14.7 — Controlling I/O

Monitoring, Forcing & Simulating

Controlling I/O lets you test your system during commissioning and troubleshooting. Three modes are available: Monitoring (viewing), Forcing (changing outputs), and Simulating (testing without real signals).

14.7.1 — Monitoring I/O

Simply navigate to MENU → I/O → select the type. Watch signals update in real time as external devices operate. Switch between inputs and outputs with F3 IN/OUT. Sort by number (F2 NUMSRT) or comment (F3 CMT-SRT) using NEXT.

14.7.2 — Forcing I/O

Only Outputs can be forced directly — they are signals sent by the controller. To force an Input, it must first be simulated.

⚠️
WARNING: Forcing digital outputs causes connected devices to physically function. Know exactly what each output controls and how it will move before forcing it — otherwise personnel or equipment could be injured or damaged.
Procedure 14-4: Force Digital Output from I/O Screen
1
MENU → I/O → Digital → ENTER
2
Display Digital Outputs (F3 IN/OUT if needed)
3
Cursor to STATUS of the output to force
4
F4 ON or F5 OFF

For Group Outputs: navigate to the Group I/O screen and enter the numeric value directly.

Procedure 14-5: Force Output via Program Instruction
1
Place cursor on blank line in program
2
Press F1 [INST] → I/O

Press NEXT first if [INST] not visible on F1.

3
Choose the desired instruction type

Select DO[ ]=, RO[ ]=, GO[ ]=, etc. from the I/O statement menu.

4
Enter signal number and desired state

Options: ON, OFF, Pulse (width), R[ ], or (…) expression.

GRIPPER_OPEN
1RO[1:Grip Open] = ON
[End]
14.7.3 — Simulating I/O

Simulating forces signals without real electrical signals entering or leaving the controller. Use it to test program logic when I/O devices aren't yet connected. Works for digital, analog, group, and robot I/O. Cannot simulate UOP or SOP I/O.

1
MENU → I/O → select type → ENTER
2
Cursor to the SIM column of the signal
U = Unsimulated   S = Simulated
3
F4 SIMULATE / F5 UNSIM

Once simulated, the signal can be forced ON or OFF using F4 ON / F5 OFF. Real hardware state is ignored.

4
Unsimulate all: FCTN → UNSIM ALL I/O

Clears all simulated signals at once from the FUNCTION menu.

14.8 — Saving I/O Configuration

Always save I/O configuration data so it can be reloaded if settings are lost or altered.

PROCEDURE 14-7 — SAVE I/O SETTINGS
1. Set the Default Device (Section 7.4.1)
2. Navigate to the Digital I/O Screen
3. Press FCTN → -0- NEXT → SAVE
→ File saved: DIOCFGSV.IO

Chapter Labs

LAB 23
Create a Group Output
Configure a Group Output from a set of Digital Outputs, force it to a value, and verify the correct physical outputs activate.
  1. Determine parameters for DO[3–9] as GO[1] — See Section 14.5.4 (pg. 231)
    • Rack: ____
    • Slot: ____
    • Start Point: ____
    • Number of Points: ____
  2. Enter data into the Group Output screen to configure GO[1] — See Section 14.6.1 (pg. 235)
  3. Force GO[1] to a value of 97 and verify at the Digital Output screen which DO signals are ON
  4. Darken the outputs that are ON in the diagram (DO[3] through DO[9]) and note each bit value
  5. Confirm: Do the active outputs represent the binary value of 97?
  6. Save I/O configuration to the Individual Files directory — See Section 14.8 (pg. 241)
LAB 24
Create an I/O Program
Create two non-motion programs to open and close the robot gripper using Robot Output instructions.
  1. Confirm Robot Outputs controlling the gripper are complemented — See Section 14.5.5 (pg. 232)
  2. Create a new program called A_GRIP_OPEN
  3. In Program Detail, disable motion group one (non-motion program) — See Section 11.6.5 (pg. 168)
  4. Add instruction: RO[x] = ON (x = gripper open signal) — See Section 14.7.2 (pg. 238)
  5. Create a new program called A_GRIP_CLOSE (hint: use the copy feature)
  6. In Program Detail, disable motion group one
  7. Add instruction: RO[x] = OFF
LAB 25
Create a Material Handling Program
Build a complete pick-and-place program using motion instructions combined with I/O instructions to control a gripper.
  1. Create a new program called A_PICK_PART
  2. Place the cylinder in the ring marked "PICK POS 1"
  3. From HOME, jog to above the part → record as local position, name "Above Pick"
  4. Jog down to the part → record as PR[6], name "Pick Pos"
  5. Add I/O instruction to close gripper (pick the part)
  6. Return to "Above Pick"
  7. Jog to above the drop position → record as local position, name "Above Drop"
  8. Jog down to drop position → record as PR[7], name "Place Pos"
  9. Add I/O instruction to open gripper (release the part)
  10. Return to "Above Drop"
  11. Test the program (Step Test → Continuous → Auto)
A_PICK_PART — SYNTAX13 LINES
1UFRAME_NUM=1
2UTOOL_NUM=1
3;
4J PR[1:HOME] 100% FINE
5J P[1:Above Pick] 100% CNT50
6L PR[6:Pick Pos] 250mm/sec FINE
7RO[1:Grip Open] = OFF
8J P[1:Above Pick] 100% CNT50
9J P[2:Above Place] 100% CNT50
10L PR[7:Place Pos] 250mm/sec FINE
11RO[1:Grip Open] = ON
12J P[2:Above Place] 100% CNT50
13J PR[1:HOME] 100% FINE
[End]
