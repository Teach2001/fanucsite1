17.2 — Overview

Position Registers Overview

Position Registers store global positional data — X, Y, Z, W, P, R, and configuration — for shared use across many programs. They can define where the robot moves, store frame data, joint angles, and offset values. Up to 372 Position Registers are available on an R-30iB PLUS controller.

PR[x]
Whole Register
Manipulates the entire position register at once — assignment and arithmetic on all X, Y, Z, W, P, R elements simultaneously. Use to store LPOS, JPOS, copy another PR, or apply tool/user frames.
PR[i,j]
Element Instruction
Targets a specific element (i = register number, j = element 1–6 for X/Y/Z/W/P/R). Allows precision manipulation of a single axis value — for example, adding 50mm to Z only.
Offset
PR Offset Motion Option
Appended to a motion instruction as Offset,PR[x]. Shifts the target position by the values stored in the PR — only for the line where it appears.
📌
If the controller has multiple motion groups, the number of Position Registers per group may be reduced depending on how many groups are present.
17.3.1 — PR[x] Instructions

PR[x] Position Register Instructions

PR[x] instructions manipulate the entire position register. They include assignment (=) and arithmetic (+/−) instructions.

Assignment — PR[GRPn:x] = [value]

Sets the value of the item on the right into the PR on the left.

PR[GRPn:x] = [value]
↑ GRPn: Group number (1–3), optional
↑ x: PR number (Direct 1–32, or Indirect R[x])

Value options:
LPOS — current Cartesian coordinates (X,Y,Z,W,P,R)
JPOS — current joint angles
PR[x] — contents of another PR
P[x] — contents of a taught point
UFRAME[] / UTOOL[]
Arithmetic — PR[GRPn:x] = [value] [op] [value]

Adds or subtracts two items and stores the result in a PR.

PR[x] = [value] + [value]
PR[x] = [value] − [value]

Left-side value sources:
LPOS, JPOS, UTOOL[x], UFRAME[x], PR[x], P[x]

Operators: + addition, − subtraction, <cr> terminate without operator
Example Usage
PR EXAMPLES
1:PR[1]=LPOS// Store current Cartesian position
2:PR[2]=JPOS// Store current joint angles
3:PR[3]=PR[1]// Copy PR[1] into PR[3]
4:PR[4]=P[1]// Copy taught point P[1]
5:PR[5]=PR[1]+PR[2]// Add two PRs
6:PR[GRP1:1]=LPOS// Group-specific assignment
[End]
📌
When manipulating values with a Position Register, the data is relative to the active User and Tool Frame.
17.3.2 — PR[i,j] Element Instructions

PR[i, j] Position Register Element Instructions

PR[i, j] targets a specific element of a position register. i = the register number, j = the element within that register (1–6 for Cartesian, 1–n for Joint).

jCartesian Element
1X — lateral
2Y — longitudinal
3Z — vertical
4W — roll rotation
5P — pitch rotation
6R — yaw rotation
jJoint Element
1Joint 1 (J1)
2Joint 2 (J2)
3Joint 3 (J3)
4Joint 4 (J4)
5Joint 5 (J5)
6Joint 6 (J6)
Assignment — PR[i,j] = [value]

Sets a single element of a PR to the specified value. Value sources include I/O signals, constants, registers, timers, and other PR elements.

PR[i, j] = [value]

Common value sources:
Constant value
R[x] — Data Register
DI[x]/DO[x], RI[x]/RO[x]
AI[x]/AO[x] — Analog I/O
GI[x]/GO[x] — Group I/O
PR[x,y] — another PR element
TIMER[x] — timer value
Arithmetic — PR[i,j] = [value] [op] [value]
PR[i, j] = [value] + − * / DIV MOD [value]

Operators: + − * / DIV MOD
Mix rules: + and − together OK; * and / together OK
Cannot mix + with * in the same instruction
Max 5 operators per instruction
Practical Examples
PR[i,j] EXAMPLES
1:PR[5,3]=0// Set Z element of PR[5] to 0
2:PR[5,3]=PR[5,3]+50// Add 50mm to Z
3:PR[5,3]=100// Set Z = 100mm directly
4:PR[6,1]=PR[6,1]+65// Shift X by 65mm each cycle
5:PR[5,3]=PR[5,3]+15// +15mm Z per cycle (Lab 30)
[End]
⚡
PR[i,j] is the key to incremental offsetting. By adding a delta to a single element each cycle, the robot shifts its path incrementally — perfect for stacking or palletizing applications.

17.4 — OFFSET, PR Motion Option

OFFSET, PR[x] Motion Option

The Offset, PR[x] motion option shifts a target position by the X, Y, Z, W, P, R values stored in a Position Register. It is appended directly to a motion instruction and applies only to that single line.

⚠️
Critical Rules: The offset applies ONLY to the motion instruction where it appears. All six elements of the Position Register must be initialized — no element can be uninitialized (even if offsetting in only one direction).

17.4.1 — Key Rules for OFFSET, PR[x]
  • Relative to active USER Frame Offset data in the PR is interpreted relative to the currently active USER Frame orientation — not the World frame.
  • Single-instruction scope The offset is applied ONLY to the motion instruction where it appears. Other motion lines are unaffected.
  • All elements must be initialized Even if you only want to offset Z, all six elements (X, Y, Z, W, P, R) must have values — none can be uninitialized or left as *.
  • Cartesian PR: adds element-by-element Each element of PR[x] is added to the corresponding element of the target position. Position is internally converted to Cartesian if needed.
  • JOINT PR: no offset user frame If PR[x] is in JOINT representation, each joint angle element is added. No offset user frame is applied in this case.
  • TOOL OFFSET, PR[x] variant Choosing TOOL OFFSET, PR[x] instead offsets the position relative to the Tool Frame orientation rather than the User Frame.

17.5 — Miscellaneous Instructions

Miscellaneous Instructions

Miscellaneous instructions handle timer control, speed override, program annotation, and user messaging. All are accessed via Miscellaneous from the [INST] menu.

⏱️
Timer
TIMER[x] = action
Start, stop, or reset up to 20 independent program timers. Timers can span multiple programs — start in one program, stop in another. Useful for cycle time measurement.
⚡
Override
OVERRIDE = x%
Sets the speed override as a percentage (0–100%) of the programmed speed. Allows in-program speed adjustment without editing motion instructions individually.
💬
Remark
! remark text
Annotates the program. Remarks do NOT affect execution. 1–32 characters. First character is always an exclamation mark (!). Can be highlighted yellow via EDCMD Color command.
📢
Message
MESSAGE[content]
Displays a message on the USER screen when executed. 1–23 characters. The user screen is shown automatically. Leave content empty for a blank separator line between messages.
Timer Instruction Syntax
TIMER[x] = START — starts the timer
TIMER[x] = STOP — stops the timer
TIMER[x] = RESET — resets to zero

x: Direct timer number 1–20
or Indirect R[x] (contents = timer number)

// Store elapsed time in a register:
R[10] = TIMER[1]
Override Instruction Syntax
OVERRIDE = x %

x: Speed percentage 0–100%

Examples:
OVERRIDE = 50 % // Half speed
OVERRIDE = 100 % // Full speed
Remark & Message Syntax
// Remark instruction (no execution effect):
!remark text
1–32 characters; first char must be !

// Message instruction (displays on USER screen):
MESSAGE[message content]
1–23 characters
Empty brackets = blank line on screen

Lab Exercises

LAB 30
Position Register Offsets
Modify A_COUNTER into A_OFFSET — a program that offsets its path by +15mm in Z on every cycle, running 5 cycles total.
  1. Copy A_COUNTER → rename A_OFFSET
  2. Modify the program to offset above the current path by a specific distance
  3. Assign a PR for offset data — manually set all 6 elements to zero at the DATA screen (e.g., PR[5])
  4. Initialize both registers outside the main loop: PR[5,3]=0 and R[1:Cycle Count]=0
  5. Add Offset,PR[5] to each motion instruction in the loop
  6. Increment Z element each cycle: PR[5,3]=PR[5,3]+15
  7. Increment counter and use IF to loop 5 times: IF R[1:Cycle Count]<5, JMP LBL[1]

LAB 31 — FINAL EXERCISE
Applying All Course Concepts
A comprehensive final program combining PRs, offsets, macros, timers, group outputs, and conditional branching into a multi-pick program that runs 3 cycles.
  1. Copy A_PICK_PART → rename A_MULT_PICK
  2. Create PR[10] for height offset above pick/place positions (e.g., Z=50mm, all others=0)
  3. Replace "Above Pick" local positions with PR[6:Pick Pos] + Offset,PR[10]
  4. Replace "Above Place" local positions with PR[7:Place Pos] + Offset,PR[10]
  5. Determine X offset distance to second pick position (relative to USER Frame)
  6. Do the same for the drop position using PR[7]
  7. Add PR[i,j] instructions after each pick/place to shift position for the next part
  8. Replace gripper I/O instructions with MACRO Command Instructions (Gripper will Close / Open)
  9. Set PAYLOAD schedules: "tool w/ part" after pick, "tool only" after place
  10. Initialize PR X values at program start using PR[i,j]
  11. Add Data Register counter + IF to loop exactly 3 cycles
  12. Track full cycle time: TIMER[1]=RESET → START → STOP → R[10]=TIMER[1]
  13. Add Remark instructions to annotate each program section
  14. Use Group Output to reflect current part number: GO[1]=R[5]
