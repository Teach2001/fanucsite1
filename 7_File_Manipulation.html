7.2 — Controller Memory

Controller Memory Overview

The FANUC controller uses three distinct types of memory, each with different characteristics, purposes, and backup requirements. Understanding these differences is essential for proper data protection.

DRAM
Dynamic Random Access Memory
NOT battery backed — volatile
Contents lost when power is removed
Also called "TEMP" (temporary memory)
System software executes here during runtime
TEMPORARY / VOLATILE
SRAM
Static Random Access Memory
Battery backed — nonvolatile while battery works
Contents retained when power is removed
Also called "CMOS" or "PERM" (permanent memory)
TPP pool: teach pendant programs
PERM pool: system variables, KAREL variables
A portion can be used as RAM Disk (RD:)
BATTERY-BACKED / USER DATA
F-ROM
Flash Programmable Read Only Memory
NOT battery backed but non-volatile
Contents retained when power is removed
Used for permanent storage of system software
File-oriented — allocated to flash file system
Contains both system and user files
Available for user storage as FROM device (FR:)
NON-VOLATILE / SYSTEM SOFTWARE
⚠️
CAUTION: Data in SRAM can be lost if the battery is removed, loses its charge, or if new core software is loaded. SRAM will last only 30 minutes without the battery when power is off. Back up all files regularly to prevent data loss.

7.4 — Preparing for Backup

Preparing to Create a Backup

Before performing any backup, complete the following preparation steps in order. Not all steps are required in every situation.

Step 1 — Set the Default Device

You must set the default device before any program or file manipulation, including formatting. The selected device remains active until changed.

Step 2 — Format the Device (First Use Only)
⚠️
WARNING: Format the device only before its FIRST use. Formatting after first use will erase all data stored on the device. USB memory sticks plugged into the iPendant connector (UT1:) cannot be formatted — use the controller front panel USB or a PC.
Format as FAT if:
Device is less than 2 GB
255 or fewer files in root directory
Larger quantities go in sub-directories
Faster write speed is needed
Format as FAT32 if:
No limit to files in root directory needed
Device is larger than 2.0 GB

7.5–7.6 — File Backup & Restore

File Backup & Restore

A File Backup saves program, system, application, diagnostic, and error log files from SRAM to the default device. Application software (HandlingTool, etc.) is NOT backed up using the FILE menu — use Image Backup for that.

1
Press MENU → File → File

Navigate to the File screen via the main menu.

2
Set the Default Device

Verify the correct storage device is selected (see Section 7.4.1).

3
Format if Necessary

Format the device only if it is being used for the first time (see Section 7.4.2).

4
Create Subdirectory if Needed

Navigate to or create the target subdirectory to organize backup files (see Section 7.4.3).

5
Press F4 [BACKUP]

The BACKUP menu opens with file type options.

6
Select "8 All of Above"

Highlight "All of Above" and press ENTER, or press 8 on the keypad to back up all file categories.

7
Press F4 [YES] to Delete and Backup

This deletes the existing directory contents first — necessary because each backup uses identical file names and duplicates cannot exist in the same directory.

8
Wait for Completion

A scrolling list shows files being saved. When complete, the total number of files saved is displayed (e.g., "Total 191 files saved").

A File Restore overwrites existing SRAM data on the controller. Not every file is always restored — write-protected System Macros and KCL files will not be overwritten (this is normal).

ℹ️
Controlled Start Required: A File Restore must be performed in Controlled Start mode. This prevents the system from running programs while files are being loaded.
1
Enter Controlled Start Mode

If controller is OFF: Hold PREV + NEXT keys and turn on the controller — select "Controlled Start" from the Configuration Menu.
If controller is ON: Press FCTN → Next → Cycle Power → CTRL → YES.

2
Press MENU → File

From the Controlled Start screen, navigate to the File menu.

3
Set the Default Device

Set the device to match where the backup was saved.

4
Navigate to the Backup Directory

Go into the subdirectory that contains the backup files you want to restore.

5
Press F4 [RESTOR]

If F4 shows [BACKUP], press FCTN and select RESTORE/BACKUP to toggle to [RESTOR].

6
Select "All of Above" → F4 [YES]

Confirm the restore. Files will be loaded from the USB/device into controller SRAM.

7
Cycle Power — Cold Start

Once restore completes, press FCTN → Start (Cold) → ENTER to resume normal operations.

7.7–7.8 — Image Backup & Restore

Image Backup & Restore

The Image Backup creates a complete copy of F-ROM and SRAM as a set of .img files on the selected device. It is available from the FILE menu in Cold or Controlled Start mode. The actual backup occurs on the next power-up after selection.

1
Access FILE Menu in Cold/Controlled Start

Press MENU → File → File. Image Backup is only accessible in Cold or Controlled Start mode.

2
Set Default Device and Create Directory

Set the destination device and navigate to or create a subdirectory (e.g., Initial_Image_061318).

3
Press F4 [BACKUP] → Page 2 → Image Backup

On the BACKUP menu's second page, select "Image Backup" (option 2) by highlighting and pressing ENTER, or press 2.

4
Confirm Current Directory → F4 [OK]

Verify the directory path shown is correct, then press OK to initiate the power cycle. The controller will restart and the image backup runs automatically on power-up.

5
Backup Runs Automatically

You will see files being written (FROM00.IMG, FROM01.IMG, SRAM02.IMG, etc.). The controller cycles power again when complete and displays "Image backup completed successfully."

IMAGE BACKUP — PROGRESS DISPLAY
WRITING MC:\FROM00.IMG ... Done
WRITING MC:\FROM01.IMG ... Done
WRITING MC:\FROM02.IMG ... Done
...
WRITING MC:\SRAM02.IMG ... Done
DONE!

The Image Restore loads the saved F-ROM and SRAM back into the controller from .img files. This is performed via the BMON (Boot Monitor) screen — a special low-level boot environment.

⚠️
CAUTION: Image Restore ERASES all of SRAM and FROM before loading. Be absolutely certain you want to erase everything. If restoring to a different controller, an OPTN-027 alarm (ID Mismatch) will appear — contact FANUC America Corporation for ID correction.
1
Access BMON Screen

Press and hold F1 + F5 while turning on the power disconnect circuit breaker. The Boot Monitor (BMON) screen appears.

2
Select Controller Backup/Restore

From the BMON menu, select option 4 "Controller backup/restore" and press ENTER.

3
Select "Restore Controller Images"

From the BACKUP RESTORE MENU, select option 3 "Restore Controller Images".

4
Select the Storage Device

Choose the device where the image files are stored (Memory Card, Ethernet, USB UD1, USB UT1).

5
Select the Subdirectory

Navigate to the directory containing the .img files. Press 1 to select the current directory.

6
Confirm and Begin Restore

Press 1 for YES to begin. The controller verifies memory sizes, then clears SRAM and FROM and loads all image files (approximately 3–6 minutes).

7
Return to BMON → Configuration Menu → Cold Start

Once complete press ENTER to return to BMON. Select Configuration Menu, then Cold Start. DO NOT select INIT Start — this will clear all memory.

ℹ️
Key Sequence to Access BMON: Hold F1 + F5 while powering on. Compare: Controlled Start = hold PREV + NEXT while powering on.
7.9 — Generating a Directory

Generating a Directory

A directory is a list of files on a specific storage device. Press F2 [DIR] from the File screen to generate a file listing. You can display all files or filter by extension.

  • *.* — All FilesDisplays every file in the current directory regardless of extension.
  • *.TP — TP ProgramsShows only teach pendant program files (.TP extension).
  • *.VR — Variable FilesShows system and user variable files including registers and frame data.
  • *.SV — System FilesShows system configuration files like SYSVARS, SYSSERVO, SYSMAST, SYSFRAME.
📋
Procedure 7-8: MENU → File → File → Set device → Navigate to directory → F2 [DIR] → select file extension from popup.
