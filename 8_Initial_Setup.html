8.2 — Axis Limits

Axis Limits Setup

Axis limits define the motion range of the robot. The operating range can be restricted because of work area limitations, tooling and fixture interference, and cable or hose lengths. There are three layered methods — each acting as a safety net for the next.

01
Software Settings
INNERMOST BOUNDARY
Upper and lower degree limitations set in the controller software. Can be configured for all robot axes. The robot performs a controlled stop when limits are reached — if the robot is calibrated. If not calibrated, the next layer (overtravel switches) engages 2–3° beyond.
02
Overtravel Switches
MIDDLE BOUNDARY (OPTIONAL)
Physical overtravel switches located 2–3° beyond the software limits. When tripped, they cut power to the servo motors immediately. Available as an option for axis 1. These switches protect against uncalibrated software limit violations.
03
Hard Stops
OUTERMOST BOUNDARY
Physical barriers located 2–3° beyond the overtravel switches or software settings on the three major axes. The robot physically cannot move beyond a hard stop. When software limits are changed, the hard stops must be adjusted to match.
⚠️
WARNING: Do not use axis software limits as the only method for restricting robot motion. Change the hard stops to match the software modifications; otherwise, you could injure personnel or damage equipment.
⚠️
CAUTION: Changing axis limits will affect the robot work area and could change robot motion. Anticipate the effects before changing them — unexpected results could occur, such as errors in previously recorded positions.
8.3 — Software Settings

Axis Limits Software Settings

SYSTEM AXIS LIMITS — INTERACTIVE DISPLAY

ℹ️
Smaller value always goes in LOWER column. Larger value in UPPER column. Positive values assumed — specify negative values explicitly.
  • AXIS ColumnDisplays the number for each robot axis (1–6 for a standard 6-axis robot). Axes 7–10 with GROUP=0 indicate those extended axes are not present.
  • GROUP ColumnIndicates which motion group each axis belongs to. A "0" means the robot does not have those axes configured.
  • LOWER ColumnThe lower limit of each axis — the axis limit in the more negative direction. You can change these values. Not always a negative number.
  • UPPER ColumnThe upper limit of each axis — the axis limit in the more positive direction. You can change these values. Not always a positive number.
📋
Procedure 8-1: MENU → Next → System → Axis Limits → cursor to axis → type new value → ENTER → repeat → cycle controller power to apply changes.

8.4 — Payload

Payload Setup

Payload data is vitally important and must be as accurate as possible. Accurate payload improves Collision Guard, Soft Float, positional accuracy, cycle time, and general motion performance. Set payload whenever tooling changes or a workpiece is added or removed.

ℹ️
If payload has not been set, the NOTIFICATIONS icon will flash in the upper right corner of the teach pendant screen. Up to 10 payload schedules by default, maximum 32. Specify a schedule using payload setup screens or PAYLOAD program instructions.

Payload tells the robot: what it is moving (mass), where the mass is centered (COG), and how the load affects motion (inertia).

Payload Setup Methods
✏️
Manual Entry
Values are known from engineering calculations or tooling data sheets. Enter mass (kg), COG X/Y/Z (cm), and Inertia X/Y/Z (kgfcms²) directly into the schedule via MOTION → DETAIL screen.
🤖
Payload Ident (Option J669)
Automatic payload estimation available on some robot models. The robot moves through a motion sequence and calculates payload automatically. If unsupported, "IDENT is not supported to this robot" is displayed when F2 IDENT is pressed.
⚙️
Payload Instructions
Program instruction that sets the active payload schedule as the program executes. Essential when picking/dropping parts or performing tool changes. Insert via F1 [INST] → Page 2 → Payload → PAYLOAD[…].
8.4.3 — Arm Load

Arm Load Information

Arm Load tells the robot what additional mass is attached at J1 and J3 — such as valve packs, cable management systems, or other peripheral devices mounted on the arm rather than at the tool.

Think of it like wearing a backpack. As weight is added, it places increasing strain on your body and must be compensated for. Unaccounted arm loads impact motion, accuracy, and functionality of software options like Collision Guard.

  • J2 Base Load [kg]Mass attached at the J1/J2 area — such as cable bundles, conduit management, or valve manifolds mounted on the lower arm or base.
  • J3 Arm Load [kg]Mass attached at the J3 area — devices mounted mid-arm such as upper arm cable management or cooling systems.
  • J3 Casing Load [kg]Mass of any casing or covering mounted at J3 that adds to the arm's overall weight distribution.
📋
Procedure 8-4: MENU → Next → System → Motion → select schedule → F4 ARMLOAD → enter J2 Base Load, J3 Arm Load, J3 Casing Load → F4 YES to confirm.

8.5 — Mastering

Mastering Overview

Mastering defines the physical location of the robot by synchronizing mechanical information with positional information. A robot must be mastered to operate properly. Robots are typically mastered before leaving FANUC, but mastering data can be lost.

  • Closed Loop Servo SystemController outputs command signals to drive each motor. A Serial Pulse Coder (SPC) on each motor sends feedback. The controller analyzes feedback and adjusts commands continuously to maintain accurate position and velocity.
  • What Mastering RecordsMastering records the serial pulse coder reading at a known mechanical reference point on the robot. This data is stored in SRAM and maintained by a backup battery when powered down.
  • Calibration (Automatic)Each time the controller is powered on, it requests the stored SPC reading. When received, the servo system can operate normally. This automatic process is called calibration — it happens every power-on.
  • Why It MattersIf mastering is wrong before recording positions, when mastering values are later corrected, ALL program points will be off by the amount of the mastering error. Always verify mastering first.
Mastering — Servo Loop Diagram
Verify Mastering
✅ MASTER VERIFIED
Alignment marks line up at 0° for all axes. Marks aligned = robot is mastered correctly. Safe to proceed with programming.
❌ MASTERING REQUIRED
Alignment marks do not line up at 0°. Mastering must be performed before recording any positions.

Three styles of alignment marks are used depending on robot model and age:

📏
Old Style Scribe Mark
A simple scribed line on the joint housing. When the marks on both sides of the joint align at 0°, mastering is verified.
🔢
Vernier Scale
A precision scale similar to a caliper's vernier. Provides much finer mastering accuracy. The main scale line and vernier scale line must align at 0°.
📐
New Style Scribe Mark
Modern engraved marks on joint surfaces. Clean, durable reference marks that align clearly when the axis is at the zero position.
📋
Procedure 8-5: Use the POSN screen to jog each axis to 0°. Check alignment marks for each axis. If all marks align → master verified. If any marks do not align → mastering must be performed.
