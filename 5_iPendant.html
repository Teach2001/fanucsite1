5.2 — iPendant Overview

Primary Robot Interface

The iPendant is the primary means of interacting with the robot. Included with the R-30iB Plus or R-30iB controller, it provides a full-featured interface for programming, testing, and monitoring the robot system.

🖥️
Color Touch Display
Color graphics interface with optional touch screen. Supports multiple simultaneous windows and a 3D graphics engine for visualizing the robot, tooling, and work cell in desktop-quality detail.
🔑
Safety Devices
ON/OFF enable switch on the top-left, two three-position DEADMAN switches on the back, and a red Emergency Stop button on the front upper-right. All critical for safe operation.
⌨️
Dedicated Keypad
Purpose-built keys for navigation, robot motion, editing, and execution. Five context-sensitive soft keys (F1–F5) change function based on the current screen and cursor position.
🌐
Advanced Features
USB port, popup menus, integrated Help and Diagnostics, haptic feedback (option), touch screen (option), internet/intranet access (option), and iHMI Guides on the R-30iB Plus.

Select a DEADMAN switch position above to see the result.
  • Three-Position SwitchTwo DEADMAN switches on the back of the iPendant. Each has three positions: Released, Center (middle), and Fully Gripped.
  • Center = Motion AllowedRobot motion is only allowed when at least one DEADMAN switch is held in the center position for the full duration of all manual motion (jogging and program testing).
  • Released or Full Grip = No MotionReleasing removes servo power and immediately applies brakes. Fully gripping also stops motion. Only the center position enables robot movement.
Emergency Stop Button
  • Location & ActionLarge red button on the front upper-right of the iPendant. Press to stop the robot immediately in any emergency, accident, or failure situation.
  • Always Active (ON or OFF)The E-Stop button functions regardless of whether the iPendant is enabled or disabled. It is always active. Rotate clockwise to disengage after an E-Stop.
  • Non-Emergency: Use HOLDThe HOLD key stops the robot in a controlled manner with less mechanical stress. Prefer HOLD for planned stops during programming and testing.
E-Stop Button — Front of iPendant
⚠️
CAUTION: Under certain load/speed conditions pressing E-Stop could damage mechanical units. In non-emergency situations, use HOLD instead.
5.3.4 — Keys

iPendant Keys

Standard Material Handling Keypad
  • Hard KeysEvery key except F1–F5 is a hard key — its function never changes regardless of which screen is displayed. Examples: HOLD, RESET, SHIFT, ENTER, arrow keys.
  • Soft Keys (F1–F5)Five function keys whose labels change based on the current screen and cursor position. The active labels are always displayed on screen above the keys. Always check before pressing.
  • Two Keypad StylesStandard Material Handling Keypad uses English text labels. Global Symbol Keypad uses icon-based labels. Both operate identically — the functions are the same.
F1–F5 (SOFT KEYS)
Context-sensitive. Label changes with the displayed screen. Always read the label before pressing.
PREV
Restores the most recent screen state. May not always return to the immediately preceding status.
NEXT (▶)
Displays the next set of soft key choices when more than five options are available.
MENU
Displays the top-level screen menu for navigating to any software section.
FCTN
Opens the Function menu — Save, Abort All, Cycle Power, Quick/Full Menu, and more.
SELECT
Displays the program selection screen listing all stored programs.
EDIT
Displays the program edit screen for writing and modifying robot programs.
DATA
Displays the program data screen — registers, position data, and variables.
i KEY
Special key. Combined with others to display 4D views, position registers, and related menus.
COORD
Selects jog coordinate system. SHIFT + COORD opens the coordinate selection menu.
GROUP
Switches between motion groups when multiple groups are configured in the system.
OVERRIDE (%)
Adjusts the feedrate override percentage — controls how fast the robot moves.
SHIFT (Left & Right)
Required to jog the robot, teach position data, and start programs. Both SHIFT keys function identically.
JOG KEYS (±X, ±Y, ±Z)
Effective only while SHIFT is held. Moves the robot along the active coordinate system axes.
EXTENDED AXIS KEYS
Used to jog extended axes or servo gun axes independently of the main robot axes.
COORD
Selects the active jog coordinate (Joint, World, Tool, User). Hold SHIFT + COORD to change.
HOLD
Halts a running program in a controlled manner. Preferred over E-Stop for non-emergency stops.
RESET
Clears an active alarm after the fault condition has been corrected and identified.
STEP
Toggles between step mode (one instruction at a time) and continuous execution mode.
FWD (SHIFT+FWD)
Starts program execution forward. SHIFT must be held — releasing SHIFT halts the program.
BWD (SHIFT+BWD)
Starts program execution backward. SHIFT must be held — releasing SHIFT halts the program.
ARROW KEYS
Highlight or select items on screen. Navigate menus and move the cursor through program lines.
BACK SPACE
Deletes the character or numeral immediately before the cursor during text or data entry.
ITEM
Moves the cursor directly to a specific line number — useful in long programs or large lists.
ENTER
Processes and activates current data entry or menu selection. Confirms all inputs.
SET UP
Displays the SETUP screen for configuring frames, tools, and system settings.
I/O
Displays the I/O screen for monitoring and simulating digital and analog I/O signals.
POSN
Displays current robot position data in the active coordinate frame.
TOOL 1 / TOOL 2
Displays the Tool 1 or Tool 2 configuration screen for gripper and tool frame settings.
STATUS
Displays the STATUS screen showing controller and system information.
MOVE MENU
Not supported in HandlingTool application software.

Status Indicators
Click indicators above to toggle. Busy = processing; Step = step mode; HOLD = hold condition; FAULT = fault occurred; RUN = program executing. Last three are application-specific.
Alarm Status Line
Displays the current active alarm. Touching this line is equivalent to pressing DIAG, which shows diagnostics for the current alarm.
Program Status Line
Shows the currently executing program name, line number, and status. Also displays the active mode: AUTO, T1, or T2.
Motion Information
Lists the active coordinate system (Joint, World, Tool, User), active motion group, and active subgroup.
Speed Override
Percentage of maximum speed at which the robot will move. 100% = maximum possible speed. Adjusted with the override keys.
LED Indicators
Two physical LEDs on the iPendant: POWER (controller is on) and FAULT (a fault has occurred). Always visible regardless of screen content.
5.5 — Screen Navigation

Screen Navigation

Split Screen Modes
SINGLE
One full window — maximum space for a single screen view.
SINGLE WIDE
Wider single window — more columns visible, ideal for program lists.
DOUBLE
Two windows side-by-side. Activate with SHIFT + DISP.
TRIPLE
Three windows — one large panel plus two stacked.
TREE VIEW
Hierarchical tree on left; content pane on right. Expand/collapse branches.
ℹ️
Split Screen Shortcut: Press SHIFT + DISP to open the Display menu and choose a window mode. You can also touch any section of the focused window's title bar to access MENU, DISPLAY, and FCTN shortcuts directly.
Menu Navigation Procedure
1
Press MENU

Opens the top-level menu. Categories include Utilities, Test Cycle, Alarm, I/O, Setup, File, and more.

2
Cursor Up / Down

Navigate to your desired item. Items with a block arrow (▶) fly out to show sub-items as you highlight them.

3
Cursor Right for Sub-Menu

Press the right arrow on a highlighted item to access its fly-out sub-menu, then navigate to the sub-item.

4
Select with Arrow Key or Number

Highlight and press ENTER, or press the corresponding number on the keypad for faster navigation.

  • Title Bar ShortcutsTouch the title bar of the focused window to access MENU, DISPLAY, and FCTN shortcuts without pressing physical keys.
  • Zoom / Maximize / RestoreTitle bar icons let you zoom into a single screen, maximize a window to full screen, or restore back to the previous split layout.
  • Touch Screen NoteItems activate on touch release, not press. Prompt and Warn boxes shown in yellow do not respond to touch-and-release events.

Menu Favorites & Quick Menus
  • Menu FavoritesStore up to 10 frequently-used menu screens for one-tap access. Navigate to a screen, press MENU, then hold a favorites tile for 3 seconds to assign it.
  • Software KeyboardFor text entry: position cursor on the target field, press ENTER, then press F5 (KEYBOARD). Supports uppercase, lowercase, numbers, and punctuation.
  • Quick / Full Menu ToggleQuick Menu shows a limited simplified list. No password needed. Procedure: FCTN → Next → Quick/Full. Identical steps toggle it back to Full Menu.
1
Navigate to Target Screen

Go to the menu or screen you want to save as a favorite using normal navigation methods.

2
Press MENU

Open the menu dialog. The favorites bar appears at the bottom of the screen with empty tile slots.

3
Hold a Tile for 3 Seconds

Depress one of the favorite tiles for three seconds. The current screen name and icon are saved to that tile position.
