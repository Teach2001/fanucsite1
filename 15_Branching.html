15.1 / 15.2 — Overview

Branching Instructions Overview

Branching instructions cause the program to branch, or jump, from one place to another. By controlling where the cursor goes next, you control how the program executes. There are three fundamental kinds of branching instructions.

LBL
Label Definition
Destination Marker
Marks a location in the program that is the destination of a branch. Used with both conditional and unconditional branching instructions.
JMP / CALL
Unconditional
Always Executes
Branches from one location to another every time it is executed regardless of any condition. Includes Jump (JMP LBL) and Sub-program call (CALL) instructions.
IF / SELECT
Conditional
Condition-Dependent
Branches only when specified conditions are true. Includes IF statements and SELECT instructions that compare register values to determine which path to take.
15.3 — Label Definition Instruction

A label marks the destination of a program branch. After a label is defined, it can be referenced by any branching instruction.

LBL[x: comment]
↑ Direct label number (integer)
↑ Comment: up to 16 numbers, letters, spaces, ; : " ( ) * _ @
15.4 — Unconditional Branching

Unconditional Branching

Unconditional branching instructions always branch from one place to another whenever they are executed. There are two types: JMP LBL and CALL.

15.4.1 — Jump Instruction (JMP LBL)
  • Jumps within the current program JMP LBL[x] causes the cursor to jump to the named label within the same program. Can jump up or down. Typically jumps up when used as an unconditional branch (to create loops).
  • Matching label required The LBL[x] instruction must exist in the same program with the identical ID number as the JMP LBL[x] instruction.
Procedure 15-1: Programming a Jump
1
Place cursor, press F1 [INST]

If F1 does not show [INST], press NEXT first.

2
Cursor to JMP/LBL → ENTER

Navigate the instruction list to option 5: JMP/LBL.

3
Choose JMP LBL[ ]

Select option 1 from the JMP statement sub-menu.

4
Enter label number on keypad

Type the integer label number and press ENTER.

5
Add matching LBL[x] at destination

Follow the same procedure but choose LBL[ ] instead. Give it the same number as the JMP LBL.

Example: Infinite Loop
FANUC_ACADEMY
6/13
4:J PR[1:HOME] 100% FINE
5:LBL[1]
6:J P[1:Square] 100% CNT50
7:L P[2] 6000cm/min CNT50

[End]
15.4.2 — CALL Instruction
  • Branches to a remote sub-program CALL causes the program to jump to another program (sub-routine). Once that program finishes, execution automatically returns to the line immediately after the CALL — no return statement needed.
MAIN
1/2
1:CALL FANUC_ACADEMY
[End]
📌
It is not necessary to add a return statement in the called sub-program. The controller automatically returns when it reaches the program END.
15.5 — Data Registers

Data Registers

A Data Register is a storage space for a number. Registers can track part counts, speed values, cycle counts, timers, and more. Up to 999 registers are available (default 200), identified globally as R[x].

R[x]
Global Access
Data Registers are accessible from any program in the controller, just like Position Registers. Changes made in one program persist across all others.
=
Direct Assignment
Use R[3]=0 to set a register to a constant. The current value is replaced with the specified value.
±×÷
Arithmetic Operations
Supports +, −, ×, ÷, DIV (whole number division), and MOD (remainder). Mix only + and −, or only × and ÷ — not both groups in one instruction. Max 5 operators per instruction.

15.6 — Conditional Branching

Conditional Branching

Conditional branching instructions branch from one place to another only when certain conditions are true. There are two types: IF instructions and SELECT instructions.

15.6.1 / 15.6.2 — IF Instructions

An IF Instruction compares a register, I/O, or system variable to a value and takes an action if the comparison is true. When false, execution continues on the next line.

  • Action: JMP LBL[x] Jump to the specified label within the current program.
  • Action: CALL program Execute a sub-program and return to the next line.
  • Condition sources Data Register R[x], I/O (DI/DO/RI/RO/SI/SO/UI/UO), Analog I/O (AI/AO), Group I/O (GI/GO), or System Variable ($-Parameter).
  • AND / OR operators Conditions can be chained with AND or OR (not mixed). Max 5 conditions per instruction.
// IF with I/O
IF DI[x] = / <> ON / OFF, JMP LBL[x]

// IF with register
IF R[x] = / <> / < / <= / > / >= value, CALL prog

// IF with AND
IF R[1]=1 AND DI[2]=ON, JMP LBL[2]
15.6.5 — SELECT Instructions

A SELECT instruction compares a register to multiple values and routes execution accordingly. An ELSE clause handles any value not explicitly listed.

SELECT R[x] =
  value1, CALL program / JMP LBL[x]
  value2, CALL program / JMP LBL[x]
  valueN, CALL program / JMP LBL[x]
  ELSE,  JMP LBL[x]
MAIN
6/6
1:LBL[1]
2:SELECT R[1]=1,CALL SQUARE
3:          =2,CALL CIRCLE
4:          =3,CALL TRIANGLE
5:          ELSE,JMP LBL[1]
[End]
⚡
The ELSE clause executes if none of the specified values match. You can only use a register value as the comparison source — SELECT cannot check I/O directly.

2

3

Pick the operator template. It can be changed later by highlighting the operator and pressing F4 [CHOICE].

Available: IF…=… / IF…<>… / IF…<… / IF…<=… / IF…>… / IF…>=…
4
Choose variable type (R[ ], DI[ ], etc.)

Select the condition source. For a cycle counter, choose R[ ].

5
Enter register number and compare value

Type the register index, then choose CONSTANT and enter the comparison value.

6

Choose the action that executes when the condition is true.

7

Enter the target label number or select the sub-program from the list.

5-Cycle Example with IF
FANUC_ACADEMY
5/16
4:R[1]=0
5:
6:J PR[1:HOME] 100% FINE
7:LBL[1]
8:J P[1:Square] 100% CNT50
9:L P[2] 6000cm/min CNT50
10:L P[3] 750mm/sec CNT50
11:L P[2] 750mm/sec CNT50
12:L P[1:Square] 750mm/sec CNT50
13:R[1]=R[1]+1
14:IF R[1]<5, JMP LBL[1]
[End]
📌
When R[1] reaches 5 the condition IF R[1]<5 is false, so the jump does NOT execute and the program falls through to END — completing exactly 5 cycles.
15.7 — Wait Instructions

Wait Instructions

Wait instructions delay program execution for a specified time or until a condition is true. While waiting, the robot executes no motion instructions. There are two types:

15.7.1 — WAIT time

Delays execution for a fixed duration. Time is specified in seconds with a minimum unit of 0.01 seconds.

WAIT time (sec)
  Direct:   time in seconds (0.01 min)
  Indirect: R[x] (contents = time in sec)
EXAMPLE
3: WAIT 1.00(sec) // 1-second pause
5: WAIT 0.50(sec) // Half-second pause
15.7.2 — WAIT condition

Delays execution until specified conditions become true, or until a timeout expires.

  • Forever (default) Program waits indefinitely until the condition is satisfied.
  • TIMEOUT, LBL[i] If the condition isn't met within the timeout period, execution branches to the specified label.
  • AND / OR operators Same rules as IF instructions — chain multiple conditions, max 5, no mixing AND and OR.
WAIT DI[1]=ON Forever
WAIT R[1]>=10 Forever
Full WAIT Example — Machine Ready Signal
FANUC_ACADEMY
14/15
5:LBL[1]
6:WAIT DI[1:Machine Ready]=ON// Waits here until DI is ON
7:J P[1:Square] 100% CNT50
8:L P[2] 6000cm/min CNT50
9:L P[3] 750mm/sec CNT50
10:L P[2] 750mm/sec CNT50
11:L P[1:Square] 750mm/sec CNT50
12:R[1:Cycle Count]=R[1:Cycle Count]+1
13:IF R[1:Cycle Count]<5, JMP LBL[1]
14:J PR[1:HOME] 100% FINE
[End]
Labs 26–28

Lab Exercises

LAB 26
Program with Branching — IF / WAIT
Create a program called MAIN1 that loops forever and conditionally calls sub-programs based on digital input signals.
  1. Create MAIN1
    • Add LBL[1] at line 1 to anchor the loop
    • IF DI[2]=ON → CALL A_SQUARE
    • WAIT 1.00(sec)
    • IF DI[3]=ON → CALL A_CIRCLE
    • WAIT 1.00(sec)
    • IF DI[4]=ON → CALL A_TRIANGLE
    • JMP LBL[1] — returns to top
  2. Verify — Confirm each DI triggers its associated program and execution loops continuously.
MAIN1
1:LBL[1]
2:IF DI[2]=ON, CALL A_SQUARE
3:WAIT 1.00(sec)
4:IF DI[3]=ON, CALL A_CIRCLE
5:WAIT 1.00(sec)
6:IF DI[4]=ON, CALL A_TRIANGLE
7:JMP LBL[1]
[End]
LAB 27
Programming with Branching — SELECT
Create a program called MAIN2 that reads a Group Input and uses SELECT to route execution to one of several sub-programs.
  1. Create Group Input using DI[5–7]
  2. Create MAIN2
    • LBL[1] at line 1
    • R[5]=GI[1] — capture group input value
    • SELECT R[5]=1,CALL A_SQUARE; =2,CALL A_CIRCLE; =3,CALL A_TRIANGLE; ELSE,JMP LBL[1]
  3. Verify — Valid input (1–3) calls the associated program once and ends. Other values loop back.
MAIN2
1:LBL[1]
2:R[5]=GI[1]
3:SELECT R[5]=1,CALL A_SQUARE
4:              =2,CALL A_CIRCLE
5:              =3,CALL A_TRIANGLE
6:              ELSE, JMP LBL[1]
[End]
LAB 28
Register Instructions — Cycle Counter
Modify A_SQUARE into A_COUNTER so it runs exactly a predefined number of cycles, then stops.
  1. Copy A_SQUARE → rename A_COUNTER
  2. Assign a Data Register as the counter (e.g., R[1])
  3. Initialize R[1]=0 before the main loop
  4. Increment R[1]=R[1]+1 inside the loop
  5. Use IF R[1]<5, JMP LBL[1] to loop 5 times then exit
  6. Verify program runs exactly 5 cycles and returns home
A_COUNTER
4:R[1]=0
6:J PR[1] 100% FINE
7:LBL[1]
9:J P[1:Square] 100% CNT50
10:L P[2] 6000cm/min CNT50
13:L P[1:Square] 750mm/sec CNT50
15:R[1]=R[1]+1
16:IF R[1]<5, JMP LBL[1]
18:J PR[1] 100% FINE
[End]
