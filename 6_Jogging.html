6.2 — Jogging Overview

What is Jogging?

Jogging is manually moving the robot axes by pressing a sequence of keys on the iPendant. Before you can add a motion instruction to a teach pendant program, you must first jog the robot to the desired position. Two key concepts govern jogging:

⚡
Jog Speed
Controls how fast the robot moves when jog keys are pressed. Expressed as a percentage of maximum speed, or as FINE/VFINE for incremental stepping. Always set a safe speed before moving.
🧭
Coordinate System
Defines how the robot moves when jogging. Options include Joint, World (XYZ), User Frame, Jog Frame, and Tool. Cartesian systems maintain a straight-line path at the tool center point.
🦺
Safety First
All personnel must be clear of the workcell. Mode switch must be in T1 or T2. DEADMAN switch must be held center. Release SHIFT or jog key at any time to stop immediately.
📍
Position Data
The POSITION screen (POSN key) displays live joint angles and Cartesian coordinates. Updated continuously as the robot moves. View only — data cannot be changed from this screen.

Recommended starting speed. Use slow speeds until you are familiar with the robot — the slower the speed, the more control you have.
  • Percentage (%) — Continuous MotionThe robot moves continuously while the jog key is held. Speed shown in the top-right corner of every iPendant screen. Ranges from 1% to 100%.
  • FINE — Incremental StepsJoint: ~0.001° per step. Cartesian: ~0.023 mm per step. Robot moves one step per key press — must release and press again to move again.
  • VFINE — Very Fine Incremental StepsJoint: ~0.0001° per step. Cartesian: ~0.002 mm per step. Extremely precise positioning. Must release and press again between steps.
  • Adjusting SpeedPress +% or −% to change in 5% increments. Hold SHIFT + +% or −% to step through: VFINE → FINE → 1% → 5% → 50% → 100%.

6.2.2–6.2.3 — Coordinate Systems

Coordinate Systems

Press the COORD key on the iPendant to cycle through coordinate systems. The active system is displayed in the upper-right corner of the screen.

Joint jogging moves each individual axis of the robot independently — J1 through J6 — in a positive or negative direction. This is the most efficient jogging method because the processor does not need to calculate a linear path or maintain TCP position along a Cartesian plane.

Joint 2 movement automatically interacts with Joint 3 movement to maintain Joint 3 in the same orientation. Some robots have positive/negative directional markings directly on the mechanical unit for reference.
  • Most Efficient MethodNo complex path calculations required. Each axis moves independently — simple and predictable.
  • J2/J3 InteractionJ2 and J3 movements are coordinated to keep J3 in the same orientation as J2 moves. This maintains tool orientation during shoulder movement.
  • Best for Large MovementsUse Joint mode to get the robot to a general area quickly. Switch to Cartesian for fine positioning.
Joint Jogging — Axis Assignments
The World Frame is a fixed, default frame of the robot that cannot be changed. It is the basis for all taught positions and frames. On most FANUC serial-link robots, the World Frame origin is at the intersection of the center of the robot base with a plane level to the Joint 2 motor.

While jogging in WORLD, motion is linear. The robot coordinates all joints to maintain a straight-line path at the end-of-arm tooling, aligned to the World Coordinate System orientation.

Tool frame jogging moves the robot relative to the Tool Center Point (TCP) and the active tool frame orientation. Motion directions are relative to the tool's own coordinate system — not the World frame. This is useful for approaching or retreating along the tool's approach direction, regardless of how the wrist is oriented.
  • TCP-Relative MotionJog directions are aligned to the tool, not the world. Z+ typically moves along the tool's approach vector — useful for approaching a surface along the tool axis.
  • Wrist Orientation PreservedWhen jogging linearly in tool frame, the TCP moves in a straight line relative to the tool frame orientation while all joints coordinate to maintain it.
User Frame (also includes Jog Frame) is a custom coordinate system defined by the operator to match a fixture, pallet, or work surface orientation. Once defined, jogging in User Frame moves the TCP relative to that custom frame — making it easier to align with parts that are not square to the World Frame.
  • Fixture-Aligned MotionIf a pallet is rotated 45° in the cell, a User Frame can be set to match it. Jogging X+ in that User Frame moves the TCP along the pallet's length.
  • Part of XYZ GroupUser Frame, World, and Jog Frame are all part of the XYZ (Cartesian) coordinate group. All three use the same linear motion principles.
Right-Hand Rule
  • What is the Right-Hand Rule?A mnemonic from mathematics and physics used to understand three-dimensional vector relationships. In robotics, it helps recall which direction each frame vector points.
  • FANUC AssignmentIndex finger = X axis. Middle finger = Y axis. Thumb = Z axis. Position your right hand with the index finger pointing toward the front of the robot (opposite the base cables) to recall World frame X, Y, and Z directions.
  • Practical UseWith the right hand correctly positioned: X points forward, Y points left, Z points up. This matches the World frame's default orientation on all FANUC serial-link robots.

6.2.5 — World Frame

World Frame Detail

World Frame — Origin & Axis Diagram
  • Fixed Default FrameThe World Frame is built into the robot and cannot be modified. It is the foundation for all taught positions, user frames, and tool frames in the system.
  • Origin LocationOn most FANUC serial-link robots, the World Frame origin is at the intersection of the center of the robot base and a plane level to the Joint 2 motor.
  • Position RepresentationPositions in World Frame are expressed as X, Y, Z (mm) for translation and W, P, R (degrees) for orientation — all relative to the World Frame origin.
  • Linear MotionJogging in World Frame produces straight-line motion. All six joints coordinate simultaneously to keep the TCP moving in a perfectly straight path.
6.3 — Jogging the Robot

Jogging Procedure

⚠️
WARNING: Make certain that all safety requirements for your workplace have been followed before jogging. Clear all personnel and unnecessary equipment from the workcell. Ensure all E-Stop and other faults are cleared. Mode switch must be in T1 or T2.
1
Enable the iPendant

Turn the teach pendant ON/OFF switch to the ON position. This gives motion control to the operator.

2
Select Coordinate System

Press the COORD key until the desired coordinate system (JOINT, WORLD, TOOL, etc.) appears in the upper right corner of the screen.

3
Set Jog Speed

Press +% or −% until the desired speed appears in the upper right corner. Start slow — use 10% or less until you are comfortable with the robot's movement.

4
Hold the DEADMAN Switch

Hold the iPendant firmly and press the DEADMAN switch on the back to the center position. Maintain this throughout all jogging.

5
Press SHIFT + Jog Key

Hold SHIFT and press the jog key corresponding to the direction you want to move. Release the jog key (or SHIFT) to stop immediately.

6
Finish Jogging

When finished, turn the teach pendant ON/OFF switch to OFF and release the DEADMAN switch.

  • Emergency Stop — Any TimeRelease the DEADMAN switch OR press the E-Stop button to stop the robot immediately at any point during jogging.
  • Stop by Releasing KeysReleasing the SHIFT key or the jog key causes the robot to stop — it will NOT continue to move after you release. Motion requires continuous key presses.
  • FINE/VFINE SteppingWhen FINE or VFINE speed is selected, the robot moves one step per key press. You must fully release and press again to take the next step.
  • Pre-Jog Checklist✓ Workcell clear of personnel ✓ E-Stop faults cleared ✓ Fault light off ✓ Mode in T1 or T2 ✓ Speed set to appropriate level
6.4 — Positional Data

Position Data Screen

The POSITION screen displays live positional information in both joint angles and Cartesian coordinates simultaneously. Updated continuously as the robot moves. Display only — values cannot be edited here.

📍
To Access: Press the POSN key at the bottom of the iPendant, or navigate via Menu → Next → 4D Graphics → Position Display.
  • Joint Section (Upper)Shows J1–J6 angles in degrees. Also displays the J2/J3 Interaction value, which is the compensation applied to maintain J3 orientation when J2 moves.
  • Cartesian Section (Lower)Shows the TCP position in X, Y, Z (mm) and orientation in W, P, R (degrees) relative to the selected frame (World or User). Also shows the robot Configuration (NUT or FUT format).
  • Switch Between ViewsUse the soft keys at the bottom — JNT (joint view), USER (user frame Cartesian), WORLD (world frame Cartesian) — to change what is displayed.
