13.2 — Edit Command Menu

Edit Command Overview

The Edit Command Menu gives the programmer access to items that change motion and non-motion instructions. It is located on the second page of soft keys in the EDIT screen under F5 [EDCMD]. It can be accessed via the Icon Editor or the fly-out text menu — both offer the same options.

COMMANDDESCRIPTION
INSERTAdds blank lines to the program. Required when adding positions or instructions — otherwise the new instruction will overwrite the existing line.
DELETERemoves one line or a range of lines from a program.
COPY/CUTCopies or cuts a range of lines and pastes them in the same or another program.
FINDSearches for a specific instance of an instruction within the program.
REPLACESearches for and replaces instructions or variable items throughout the program.
RENUMBERRenumbers position IDs (not PR's) sequentially from start to finish.
COMMENTHides or displays comments from I/O and register tables on the EDIT screen.
UNDOReverts the most recent edit operation only.
REMARKMasks out (disables) instructions by commenting them out with "//".
COLORHighlights remarked lines with a yellow background; I/O with Red (OFF) or Green (ON).
I/O STATUSDisplays or masks the current status of I/O utilized in a program.
📌
Two access methods: Press F5 [EDCMD] to open the Icon Editor with graphical buttons, or press F4 EXIT ICON to switch to the text fly-out menu. Both R30iB PLUS and R30iB software support the Icon Editor.
13.3 — Inserting Blank Lines

Inserting Blank Lines

Inserting blank lines serves two purposes: it improves readability by breaking up code visually, and it creates space to add new instructions. Blank lines have zero effect on cycle time — they are not executed by the processor. Lines are always inserted above the cursor position.

Procedure 13-1: Insert Blank Lines
1
Place cursor below the insertion point

Lines insert above the cursor, so position it on the line below where you want new space.

2
Press F5 [EDCMD]

If F5 does not show [EDCMD], press NEXT to toggle soft key pages first.

3
Select INSERT

The Edit Command menu opens. Choose the Insert option.

4
Enter the number of lines & press ENTER

Type how many blank lines to add. To insert just one line, press ENTER without typing a number.

Interactive Demo
FANUC_ACADEMY 9 LINES
1UFRAME_NUM=1
2UTOOL_NUM=1
3J PR[1:HOME] 100% FINE
4J P[1:Square] 100% CNT50
5L P[2] 750mm/sec CNT50
6L P[3] 750mm/sec CNT50
7L P[1:Square] 750mm/sec CNT50
8J PR[1:HOME] 100% FINE
[End]
TRY IT:
💡
On FANUC robots, adding an instruction without inserting first will overwrite the existing line. Always insert space before adding new code.
13.4 — Deleting Lines

Deleting Lines

You can delete a single line or a contiguous range of lines from a program. Deleted lines are permanently removed — use Undo immediately if this was unintentional.

Procedure 13-2: Delete Line(s)
1
Place cursor on the line (or first line of range) to delete

Navigate to the first line you want removed.

2
Press F5 [EDCMD] → SELECT DELETE

If F5 doesn't show [EDCMD], press NEXT first.

3
Single line: press F4 YES

Immediately confirms deletion of the highlighted line.

4
Range: move cursor to extend selection, then F4 YES

Scroll up or down — each line in the range highlights. Press F4 YES when the full range is selected.

Interactive Demo
FANUC_ACADEMY 8 LINES
1UFRAME_NUM=1
2UTOOL_NUM=1
3J PR[1:HOME] 100% FINE
4J P[1:Square] 100% CNT50
5L P[2] 750mm/sec CNT50
6L P[3] 750mm/sec CNT50
7J PR[1:HOME] 100% FINE
[End]

13.5 — Copy & Paste

Copy and Paste

Copy/paste selects a group of instructions, makes a copy, and inserts them at one or more locations in the same or a different program. Like INSERT, pasting always occurs above the cursor position.

Procedure 13-3: Copy and Paste
1
Place cursor on the first line to copy

Navigate to the starting line of the range you want to copy.

2
Press F5 [EDCMD] → COPY/CUT

Press NEXT first if [EDCMD] is not visible on F5.

3
Press F2 SELECT, then extend the range

Move cursor up or down to highlight the full range of lines to copy.

4
Press F2 COPY or F3 CUT

COPY retains the original lines. CUT removes them from the source location.

5
Navigate to destination & press F5 PASTE

Move to the line below where you want to insert, then press F5 PASTE and choose a paste method.

Source Lines (Example)
COPIED PROGRAM INSTRUCTIONS
1: J P[1] 100% CNT100
2: L P[2] 500mm/sec CNT80
3: DO[1] = ON
4: J P[3] 50% CNT50
5: L P[4] 10mm/sec FINE
6: CALL HOME

Reverse Paste Methods (13.5.2)

Reverse pasting flips the instruction order. Standard reversal simply inverts the sequence and will produce a different path. Reverse Motion pasting (RM-POSID / RM-POS) intelligently redistributes motion instructions so the robot retraces its path safely — useful for approach/retract moves where the outbound path must mirror the inbound path.

R-LOGIC
NEXT+F1
Reversed — Positions Blank
Instructions pasted in reverse order. Position numbers left blank — positions must be retaught.
7: CALL HOME
8: L P[...] 10mm/sec FINE
R-POSID
NEXT+F2
Reversed — Original IDs
Instructions pasted in reverse order, retaining the original position numbers.
7: CALL HOME
8: L P[4] 10mm/sec FINE
R-POS
NEXT+F4
Reversed — Renumbered IDs
Instructions pasted in reverse order, positions renumbered with next available IDs and data copied.
7: CALL HOME
8: L P[8] 10mm/sec FINE
RM-POSID
NEXT+F3
Reverse Motion — Original IDs
Redistributes motion instructions to maintain the path in reverse. Motion type & speed from the 2nd instruction; position data & termination from the 1st. Retains original IDs. Recommended for safe retract paths.
Path geometry preserved on the return move
RM-POS
NEXT+F5
Reverse Motion — Renumbered IDs
Same as RM-POSID but renumbers the copied positions with next available IDs. Path is preserved on the return move.
Path geometry preserved + new position IDs
💡
Reverse Motion Pasting vs Plain Reverse: If you simply paste in reverse (R-LOGIC / R-POSID / R-POS) you flip the instructions upside down — a completely different path results. RM-POSID and RM-POS restructure the motion instructions so the tool follows the same geometry back out.
13.6–13.11 — Remaining Commands

Replace, Renumber, Undo & More

13.6 — Replace (Procedure 13-4)

Replace finds specific instructions and substitutes them with new ones. Searches forward from the current cursor position to [END]. Useful when setup changes affect an entire program.

1
F5 [EDCMD] → REPLACE

Place cursor anywhere in the program first.

2
Choose the instruction category to replace

Options: Registers, Motion Modify, I/O, JMP/LBL, CALL, TIME BEFORE/AFTER.

3
Enter the search value, then the replacement

The system highlights each match as it finds it.

4
Choose how to replace each match
F2 ALL — Replace all instances at once
F3 YES — Replace this instance, find next
F4 NEXT — Skip this instance, find next
F5 EXIT — Cancel the replace operation
13.7 — Renumber (Procedure 13-5)

When positions are added or deleted, IDs can become non-sequential. Renumber reassigns all position IDs in the program to sequential order.

1
F5 [EDCMD] → RENUMBER

Cursor can be on any line.

2
F4 YES to confirm, F5 NO to cancel

After renumbering, like position IDs will share the same ID.

BEFORE → AFTER RENUMBER
BEFORE
5:J P[8:Sq] 100%
6:L P[4] 750mm/s
7:L P[7] 750mm/s
8:L P[4] 750mm/s
AFTER
5:J P[1:Sq] 100%
6:L P[2] 750mm/s
7:L P[3] 750mm/s
8:L P[2] 750mm/s
📌
Renumbering has no effect on Position Register IDs (PR[x]). Only local P[n] IDs are renumbered.
13.8 — Displaying Comments

Comments for I/O and registers can be displayed inline on the EDIT screen without opening a separate table. This is a global toggle — it applies to all programs. Press F5 [EDCMD] → COMMENT to enable/disable.

  • I/O InstructionsDI [i:COMMENT] — shows the comment inline.
  • Register InstructionsR [i:COMMENT] — shows the label for that register.
  • Position Register InstructionsPR [i:COMMENT] — shows the PR label inline.
  • Position P[ ] CommentsStored in the program itself and cannot be disabled by the Comment toggle.
COMMENT ENABLED vs DISABLED
ENABLED
4:J PR[1:HOME]
DISABLED
4:J PR[1]
13.9 — Undo (Procedure 13-6)

Undo reverts the most recent edit. Multiple modifications to the same line — if no other line was edited between them — can be recovered with a single Undo. You can also Redo the last Undo.

1
F5 [EDCMD] → UNDO

Opens the undo confirmation prompt.

2
F4 YES to undo / F5 NO to cancel

The recovered state is shown on screen.

3
To redo: F5 [EDCMD] → UNDO → F4 YES again

This re-applies the operation that was just undone.

13.9.1 — Undo Limitations
GENERAL CONDITIONS
  • Controller power cycled
  • Another program selected
  • Using a keyboard input
  • Teach pendant switch OFF
  • Program is write-protected
  • Insufficient pendant memory
HANDLINGTOOL CONDITIONS
  • Modifying palletizing commands
  • Deleting palletizing lines
  • Copying palletizing lines
  • Pasting palletizing lines
  • Line tracking instructions
  • On-line touch up executed
📌
If power fails during an Undo operation, results are unpredictable. The desired modification is not guaranteed to have taken effect when power is restored.
13.10 — Remarking Instructions (Procedure 13-7)

Remarking disables an instruction by prefixing it with //. The instruction is skipped during program execution but is not deleted. You cannot edit a remarked line until you unremark it.

You can still perform: delete, copy/paste, find/replace, and renumber on remarked lines.

1
Place cursor on the line to remark

For a range, position on the first line.

2
F5 [EDCMD] → REMARK

If [EDCMD] not visible, press NEXT.

3
Extend range by moving cursor, then confirm
F4 REMARK — disables selected line(s)
F5 UNREMARK — re-enables selected line(s)
REMARKED vs UNREMARKED
// J PR[1:HOME] 100% FINE
// J P[1:Square] 100% CNT50
J PR[1:HOME] 100% FINE
J P[1:Square] 100% CNT50
13.11 — Displaying Instructions in Color

Color mode highlights different instruction types to make programs easier to read at a glance. Toggle with F5 [EDCMD] → COLOR.

🟡
Remarked Lines
Displayed as black text on a yellow background. Makes disabled code immediately obvious.
🔴
Application Instructions (I/O OFF)
I/O instructions with OFF status are displayed in red.
🟢
Application Instructions (I/O ON)
I/O instructions with ON status are displayed in green.

Utilize EDCMD
Practice all Edit Command operations on real FANUC robot programs: copy, delete, insert, and replace across three shape programs derived from A_SHAPES.

    • Copy frame instructions from A_SHAPES and paste at top of A_CIRCLE
    • Insert a blank line between frame instructions and home position
    • Using REPLACE, change all CNT termination → FINE termination
    • Copy only the circle-tracing instructions and paste them in reverse
  3. Open A_SHAPES, copy all triangle lines, create A_TRIANGLE
    • Paste the triangle lines into A_TRIANGLE
    • Copy frame instructions from A_SHAPES and paste at top of A_TRIANGLE
    • Insert a blank line between frame instructions and home position
    • Using REPLACE, change all CNT75 → CNT50
    • Using REPLACE, change all Linear speeds from 500mm/sec → 1000mm/sec
