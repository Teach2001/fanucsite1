11.2 — Motion Program Overview

What is a Motion Program?

A program tells your robot what to do and how to do it. You must first create a program, then add instructions. A single program can move the robot, perform application operations, send output signals, respond to input signals, and track time, part count, or job number.

🤖
Robot Motion
Move the robot in an appropriate way to required locations in the workcell — the most fundamental program capability.
⚙️
Application Operations
Perform application-specific operations such as gripping, welding, dispensing, or any other EOAT action required at each position.
📡
I/O Signals
Send output signals to and receive input signals from other equipment in the workcell — PLCs, conveyors, grippers, sensors.
🕐
Tracking & Logic
Keep track of time, part count, or job number. Respond to conditions and branch program flow using registers and logic instructions.

11.5 — Creating a Program

Procedure 11-1: Create a Program

1
Press the Select key

Navigate to the Select Screen where all programs are listed.

2
Press F2 CREATE

If CREATE is not visible, press the Next key to toggle soft key pages. The "Create Teach Pendant Program" screen appears.

3
Enter the program name

Use preformed Words, Upper Case letter keys, or Options/Keybd → F5 KEYBOARD to type the name. Names convert to uppercase automatically.

4
Press F2 DETAIL or F3 EDIT

DETAIL shows program header information. EDIT opens the program immediately for adding instructions.

📝
Program Naming Rules: Max 36 characters. Must start with a letter. Letters and numbers are allowed. Only underscore (_) symbol is allowed — no @ (at), * (asterisk), or spaces. Names default to upper case after creation.

11.7 — Motion Instructions

Adding Motion Instructions

Anatomy of a Motion Instruction
JMotion Type
How to move
P[1]Positional Data
Where to move
100%Speed
How fast
FINETermination
How to stop
Motion Type (J / L / C)
J = Joint (fastest, arcing path). L = Linear (straight line, mm/sec). C = Circular arc. Determines how the robot physically moves between positions.
Positional Data P[n]
Tells the controller where to move — the recorded X, Y, Z, W, P, R position relative to the active User Frame and Tool Frame combination.
Speed
For Joint: % of max joint speed (1–100%). For Linear/Circular: mm/sec or cm/min. Set the speed to match the application safely.
Termination Type
FINE = robot stops completely at position. CNT(0-100) = robot blends through the position toward the next. In STEP mode, all moves treated as FINE.
11.7.1 — Motion Instructions and Frames

Every recorded position is relative to the active Tool Frame and User Frame. These three data items work together:

  • Tool Frame DataTells the controller where the TCP is relative to the faceplate center.
  • User Frame DataTells the controller where the User Frame origin is relative to the robot origin (World).
  • Positional DataTells the controller where the Tool Frame (TCP) is relative to the User Frame origin.
⚠️
Critical Rule: A program taught in one User Frame and Tool Frame combination will NOT run correctly if a different User Frame and Tool Frame combination is active. Always verify active frames before teaching or running a program.
Procedure 11-2: Set Frames via Jog Menu
1
Hold Shift + press COORD

Opens the Jog Menu overlay showing current coordinate settings.

2
Enter Tool frame value

Type the frame number on the Tool line using the numeric keypad.

3
Enter User frame value

Repeat for the User line. Frames are now active — confirm before recording any positions.

11.7.2 — Default Motion Instructions

Four default Motion Instructions are predefined. The last one selected becomes the active default used every time you record a position with Shift + F1 POINT.

SELECT MOTION — DEFAULT INSTRUCTIONS 1/4
1: J P[ ] 100% FINE
2: J P[ ] 100% CNT100
3: L P[ ] 100mm/sec FINE
4: L P[ ] 100mm/sec CNT100
Press ENTER to record position with selected instruction
Press F1 ED_DEF to change default without recording
Procedure 11-4: Record a Position
1
Open program → place cursor on target line

Navigate to the line where the motion instruction should be added.

2
Press F1 POINT → default instruction list appears

The four default instructions are shown in a pop-up menu.

3
Cursor to desired instruction → press ENTER

Records the robot's current position AND sets this as the new active default instruction. Any pre-existing instruction on that line is overwritten.

4
To set default without recording: press F1 ED_DEF → select → F4 DONE

Changes the active default instruction only, does not record a position.

5
Shift + F1 POINT to record subsequent positions

Jog robot to each location, hold Shift, press F1 POINT. The active default instruction is added automatically.

Procedure 11-3: Set Frames as Program Instructions

Frame instructions embedded in the program ensure the correct frames are always active when the program runs — even if the Jog Menu was changed by another operator.

1
Place cursor → press F1 INST (press NEXT if hidden)

Opens the instruction menu.

2
Navigate to Offset/Frames on page 2

Scroll through the instruction pages to find the Offset/Frames submenu.

3
Select UFRAME_NUM=… or UTOOL_NUM=…

Choose CONSTANT as the variable type, then type the frame number.

ℹ️
NOTE: Adding frame instructions to the program does NOT immediately set the active frames. The lines must be executed, OR the frames must be set manually in the Jog Menu before recording positions.

11.8 — Testing

Testing a Program

All programs must be tested before executing in automatic mode. Testing lets you verify taught positions, identify interference points, and verify program logic in a controlled way.

T1 / T2 MODE
STEP Test (11.8.1)
Executes one line at a time. Every termination type is treated as FINE — the robot stops completely at each position before waiting for your input. Maximum control. Press STEP key to enable (indicator turns yellow).

FWD = next line. BWD = previous line. Release Shift = controlled stop. Release DEADMAN = E-stop.
T1 / T2 MODE
Continuous Test (11.8.2)
Executes the full program without stopping. Each motion statement executes as programmed — CNT moves blend through positions. Gives a more accurate representation of the actual path.

Must be performed successfully BEFORE running in AUTO. Ensure STEP mode is OFF before executing.
AUTO MODE — REQUIRES TP DISABLED
Running in AUTO (11.8.4)
After successful STEP and Continuous tests, the robot runs solo without assistance. Uses the CYCLE START button. For the first AUTO run, start at a lower general override speed and slowly increase to the programmed speed.
⚠️
WARNING: Prior to executing a program in AUTO, ensure a successful STEP test AND Continuous test have been completed. For the first AUTO execution, start at a lower general override speed and slowly approach the final programmed speed. Failure to safely execute in AUTO may result in injury to personnel or damage to equipment.
Procedure 11-5: STEP Test
1
Enable the Teach Pendant

2
Select T1 or T2 Mode

T1: max 250mm/sec. T2: programmed speed.

3
Choose and open the program

Navigate to it from the Select Screen.

4
Place cursor at start point

5
Press STEP key → verify STEP indicator is yellow

6
Center the DEADMAN Switch

7
Hold Shift + press FWD to execute one line

Shift must be held for the duration of motion. FWD can be pressed and released to trigger the line.

8
Press FWD again for each subsequent line

Continue until the program is fully verified.

Procedure 11-8: Run in AUTO
1
Disable the Teach Pendant

2
Select AUTO Mode

When switching modes (T1/T2 ↔ AUTO), there will always be a fault — press Reset.

3
Choose the program

4
Place cursor at start point

5
Verify STEP mode is OFF

6
Press Reset to clear faults

7
Press Cycle Start

Aborting a Program (11.8.3)
ℹ️
If a previous program did not reach [End], abort it before running a different program. Press FCTN → select -1- ABORT (ALL). This does NOT delete any programs or data — it only ends the previously active program task.
Touching Up a Point (11.9)
1
Select program → cursor to the line

Navigate to the motion instruction that needs updating.

2
Jog robot to the new position

3
Shift + F5 TOUCHUP

Only positional data changes. Motion type, speed, and termination remain unchanged. Successful touch-up displays @ symbol next to the position (e.g. @P[3]).

ℹ️
Set New ID prompt: Appears when multiple lines share the same Position ID. YES = new ID for this line only. NO = update ALL lines with the same ID.
11.10 — Save & Restore

Saving and Restoring Program Files

Programs are saved to internal memory (SRAM) automatically as .TP binary files. Back up programs externally to protect against data loss. Programs can be saved and loaded in two formats.

💾
.TP File (Binary)
The native FANUC program format. Binary — not human-readable, but required to load back onto the robot. Save via FCTN → SAVE or Select Screen → SAVE AS.
📄
.LS File (ASCII Text)
Human-readable text version of the program. Useful for documentation, code review, and offline editing. Save via FCTN → PRINT or Select Screen → PRINT. Cannot be directly loaded as motion program.
📁
File Location
Programs are named PROGRAMNAME.TP in internal memory. For example: FANUC_ACADEMY.TP. Set the Default Device before saving or restoring any files.
Saving — Two Methods
METHOD 1 — FUNCTION MENU (FROM EDIT SCREEN)
1. Set Default Device
2. Open program on Edit screen
3. Press FCTN → -0- Next
4. Select SAVE (for .TP) or PRINT (for .LS)
5. Press Enter
METHOD 2 — SELECT SCREEN
1. Set Default Device
2. Highlight program on Select Screen (do NOT press Enter)
3. Press Next → F4 SAVE AS (for .TP) or F5 PRINT (for .LS)
4. Verify path → press F1 DO_SAVE
Restoring — Two Methods
METHOD 1 — FILE MENU
1. Set Default Device
2. Navigate to directory with the .TP file
3. Press F2 DIR → select .TP
4. Cursor to program → F3 LOAD → F4 YES
5. Confirm the load prompt
METHOD 2 — SELECT SCREEN
1. Set Default Device
2. Navigate to directory (if needed)
3. From Select Screen → press Next → F3 LOAD
4. Type the program name (case does not matter, spelling must be correct)
5. Press Enter → program loads
